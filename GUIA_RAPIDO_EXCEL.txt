═══════════════════════════════════════════════════════════
  📥 COMO BAIXAR O BACKUP EXCEL
═══════════════════════════════════════════════════════════

1. Clique no botão verde "📥 Baixar Excel" no topo da página
2. Um arquivo será baixado automaticamente
3. Nome do arquivo: caixas_backup_YYYY-MM-DD-HHMMSS.xlsx
4. Guarde esse arquivo em local seguro!

Recomendação: Faça isso semanalmente ou após mudanças importantes

═══════════════════════════════════════════════════════════
  📤 COMO RESTAURAR DO EXCEL
═══════════════════════════════════════════════════════════

1. Clique no botão azul "📤 Importar Excel" no topo
2. Selecione o arquivo .xlsx que você salvou anteriormente
3. Confirme a operação
4. Pronto! Todos os dados foram restaurados

⚠️ ATENÇÃO: Isso VAI SUBSTITUIR todos os dados atuais!

  💡 DICAS IMPORTANTES
═══════════════════════════════════════════════════════════

✓ Backup Automático Local
  • Fica salvo no navegador automaticamente
  • Não ocupa espaço no seu HD
  • Protege contra fechamento acidental do navegador

✓ Backup Manual (Recomendado!)
  • Clique em "📥 Baixar Excel" regularmente
  • Salve em pasta segura (Google Drive, OneDrive, etc.)
  • Protege contra limpeza de navegador

✓ Compartilhamento
  • Você pode enviar o Excel para outras pessoas
  • Elas podem importar no sistema delas

✓ Edição Externa
  • Abra o Excel no Microsoft Office, Google Sheets, etc.
  • Faça análises, filtros, gráficos
  • Use para relatórios e impressões
